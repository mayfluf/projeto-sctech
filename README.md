# 📊 SalesInsight PY

## 🎯 Objetivo
Este projeto tem como objetivo desenvolver um pipeline completo de análise de dados de vendas, realizando limpeza, transformação, análise e visualização de dados para geração de insights estratégicos.

## 🚀 Funcionalidades
- Leitura e inspeção de dados CSV
- Limpeza de dados (valores nulos, datas inválidas, strings)
- Criação de colunas derivadas (receita, mês, trimestre, ano)
- Cálculo de métricas com Pandas (groupby)
- Segmentação de clientes (Bronze, Prata, Ouro)
- Estatísticas com NumPy
- Visualizações com Matplotlib e Seaborn
- Exportação de dados em CSV e JSON
- Implementação de POO e herança

## 🛠️ Tecnologias
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Regex (re)
- JSON

## ▶️ Como Executar

```bash
pip install -r requirements.txt
python main.py
````
